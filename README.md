# Paralir 的安全屋 · Paralir's Safehouse

一个深绿色高冷轻恐怖风格的网安英语术语学习与闯关网站（纯静态站点，无需构建）。

> **当前版本：`v20261124e`**（提交 `d10d8e4`）　·　版本改编详情与工作留痕见 [《版本沿革志》](CHANGELOG.md)。

## 功能

- **术语检索系统**：网安专业术语检索，含英美音标、中文释义、要点示例；内置四级 / 六级 / 考研（网安方向）大词库。
- **我是单词**：按方向（Web / PWN / 逆向 / 密码学 / 杂项取证 / 四级 / 六级 / 考研）闯关。每关先从词库搜集约 30 词作为学习池，再生成 4 道小怪题 + 3 道 Boss 题，题目与干扰项全部出自该学习池；含学习倒计时、"再看一遍"、限时挑战、错题末尾统一重做、积分结算。
- **升级之路**：以 Pary、小 Rarys、Papa 为主角的世界观故事闯关。
- **社交系统**：世界频道、好友、群聊、私聊、消息撤回、排行榜。
- **管理员系统**：积分调整、定向公告、讲义中心白名单管理。
- **CTF 讲义中心**：Paralir 授权的讲义网页集合。
- **音乐工具栏**：Boss / 小怪 / 结算 / 登录音乐与可爱按键音效，可统一开关。

## 目录结构

```
paralir-safehouse/
├── index.html      入口页面
├── app.js          核心逻辑（闯关、社交、管理员、积分等）
├── data.js         词库 / 术语 / 音标数据
├── audio.js        音频与音效控制
├── gate.js         世界观门禁（注册后可见）
├── styles.css      样式
├── audio/          背景音乐与音效资源
├── lectures/       CTF 讲义中心网页
└── avatar.jpg      站点头像
```

## 本地运行

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

纯静态站点，直接托管在任意静态服务器 / GitHub Pages 均可。
